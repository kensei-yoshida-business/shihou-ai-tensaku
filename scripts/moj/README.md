# 法務省の過去問の取り込み

法務省ウェブサイトの司法試験・予備試験のページから、過去問に関係する PDF（論文式の問題・出題趣旨・採点実感、短答式の問題・正解表）を集め、`data/past-exams/` と `data/tanto/` の JSON にします。DB への投入は従来どおり `npm run db:seed` です。

## 手順

```sh
npm run moj:crawl                  # 年度別ページをたどって PDF の一覧を作る → data/moj/manifest.json
npm run moj:fetch                  # PDF を取得してテキストを抽出する → .cache/moj/（コミットしない）
python3 scripts/moj/repair-fonts.py  # 文字の対応表がない PDF を補う → .cache/moj/repaired/（要 pip install pypdf fontTools）
rm -rf .cache/moj/text && npm run moj:fetch   # 補った PDF からテキストを取り直す
npm run moj:build                  # JSON を作る
npm run moj:publish -- past-exams shihou 2025   # 原本と照合した年度を公開する（後述）
```

- 法務省のサイトはブラウザの User-Agent がないと 403 を返すので、`http.ts` で付けています。リクエストは 0.5 秒おきです。
- 新しい年度の資料（出題趣旨・採点実感は試験の数か月後に出ます）が出たら、`moj:crawl -- --refresh` からやり直します。`_reviewed: true` のファイルは上書きされません。

## 公開（published）

設計図（3-1）のとおり、取り込んだ JSON はすべて `published: false` です。原本の PDF と見比べてから `moj:publish` で公開します。

- 論文: 自動チェック（問題文の長さ、出題趣旨の有無、系科目の第N問と内容の科目の一致）を通ったものは `_autoChecked: true`。通らなかった理由は `_warnings` にあります。`moj:publish` は `_autoChecked` のものだけを公開します。
- 短答: 一問一答にできた問題だけを収録しています（正誤を正解表から機械的に導出できる形式のみ）。収録しなかった問題と理由は各ファイルの `_skipped` にあります。

## 出典の表記（利用規約）

法務省ウェブサイトのコンテンツは「公共データ利用規約（第1.0版）」で提供されていて、商用利用もできます（https://www.moj.go.jp/hisho06_00280.html ）。条件は次のとおりで、画面では `src/components/SourceNote.tsx` で表示しています。

- 出典を記載する（例「出典：法務省ウェブサイト（当該ページの URL）」）
- 編集・加工した場合はその旨も記載する（PDF からテキスト化して改行などを整えているので「…を加工して作成」と記載）
- 加工したものを国が作成したかのように見せない
- 第三者が権利を持つ部分は対象外。一般教養科目の素材文などは PDF でも「（省略）」とされており、取り込んでいません

## 一問一答にする形式

| 原本の形式 | 収録の仕方 |
| --- | --- |
| 各肢の正誤（正しいものには１を、誤っているものには２を） | each_tf。解答欄ごとの正解をそのまま肢の正誤に |
| ○×の組合せ（正しいものには○、誤っているものには×を付した場合の組合せ） | each_tf。正解の選択肢の○×を肢の正誤に |
| 正しい（誤っている）ものの組合せ | combination |
| １〜５から正しい（誤っている）ものを１つ | single_choice |
| １〜５から正しい（誤っている）ものを２個（順不同） | combination（正解の２つを１つの組合せとして） |

個数問題、穴埋め・並べ替え、見解・会話・対話の形式、「成立する場合には１を」のような正誤以外の判断を求める形式は収録しません。正解表で「受験者全員を正答」とされた問題（令和5年司法試験 刑法第6問）も除いています。

## 既知の欠落

- 司法試験 H22（2010）の問題は法務省のサイトに掲載がなく、取り込めていません。
- 令和8年（2026）の論文は、出題趣旨・採点実感がまだ公表されていないため自動チェックで止まっています。
- 予備試験 H25・H26 の憲法・行政法と R7 の法律科目の短答冊子は、PDF に文字の対応表がなく、`repair-fonts.py` で他の PDF のフォント情報から復元しています。復元できなかった字を含む問題は「文字化け」として収録していません。
- 司法試験 H23〜H26 の短答冊子は「系」ごとで科目の見出しがないため、問題番号で科目を決めています（`build-tanto.ts` の `SECTION_TAIL`）。
